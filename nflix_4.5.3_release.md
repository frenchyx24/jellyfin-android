# Nflix 4.5.3 Release Notes

## Description
- Intégration complète de Nflix Butler pour une gestion avancée des médias.
- Surveillance continue des nouveaux médias et rafraîchissement ciblé.
- Réparation des fiches incomplètes (images, résumés, identifiants).
- Accès admin sécurisé pour toutes les fonctionnalités.
- Intégration des 60 ambiances de saga data-driven.

## Installation
- Déployez le greffon Nflix Butler 0.1.5.0 sur votre serveur Jellyfin.
- Mettez à jour Nflix vers la version 4.5.3.
- Accédez aux fonctionnalités admin via l’interface Nflix.
